# Сценарии — ДОМ (прототип)

Кликабельный прототип раздела «Сценарии» базы знаний ДОМа — конвейера
редакции РМГ от текста занятия до загрузки в «Конструктор будущего».
Один HTML-файл, без сервера: данные — настоящий корпус сезона 2025/26,
состояние живёт в памяти вкладки и сбрасывается при перезагрузке.

Живой адрес: https://koclow.github.io/dom-scenarios/

## Сборка

```bash
python3 build.py
```

Собирает `index.html` из `src/`:

- `styles.css` — стили из дизайн-макетов;
- `extra.css` — стили самого прототипа (курсор, правка, тосты);
- `logo.html` — логотип ДОМа;
- `data.js` — сезоны, темы, занятия, слайды и раздатки;
- `app.js` — hash-роутер, представления, действия.

Спецификации и решения — в проекте «ДОМ (платформа команды)» студии:
`proektoria-team-platform/docs/scenarios-technical-spec.md` и
`scenarios-design-spec.md`.
